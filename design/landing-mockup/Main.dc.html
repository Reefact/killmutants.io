Mutants are small, deliberate corruptions of your production code — a flipped boolean, a shifted boundary, a swapped operator. A strong test suite kills them all. Anything left standing is a gap in your coverage you didn't know you had.
// Mutant #7 — Wallet.cs:42 — conditional boundary public bool HasSufficientFunds(decimal amount) { return balance >= amount; balance > amount; // mutated boundary } $ killmutants run --project Wallet.Tests
