# Landing page mockup — visual direction exploration

Design exploration for the killmutants.io landing page hero, palette, and a
few sample UI components (mutation report, comparison callout). Built with
Claude Design's canvas editor as a starting point for the real
implementation — not production code.

- **Live preview**: https://claude.ai/code/artifact/81cc66b2-1268-4630-a5e8-1d5b78da7ec1
- `Main.dc.html` — the mockup source (Design Component format)
- `canvas.json` — canvas layout manifest
- `banner-hero.jpg` — downsampled/re-encoded copy of `banner.png` (repo root) used as the hero background

## Direction

Horror-punk cyberpunk key art vibe, but grounded with a dirty/gritty city
texture rather than an all-neon look: near-black backgrounds, an off-white
"paint on a wall" title treatment (Rubik Wet Paint), and neon accents
(Mutant Violet, Terminal Green, Static Blue, Corrupted Red, Spark Orange)
used sparingly for CTAs, status badges, and code/terminal elements.
